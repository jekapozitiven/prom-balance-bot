# Prom Balance Bot

Телеграм-бот, который в облаке следит за балансом кошелька Prom.ua (тем, откуда списывается комиссия/доставка за заказы) и присылает уведомление, когда денег мало или баланс ушёл в минус — чтобы магазин не заблокировали. Всё делается с телефона: вход, проверки, пополнение.

## Что делает

- Работает 24/7 в облаке (Railway), твой ПК не нужен.
- Вход в кабинет — один раз, прямо из Telegram: бот вводит логин/пароль в облаке, SMS-код ты присылаешь ему в чат.
- Сессия хранится на постоянном томе и обновляется при каждой проверке, поэтому входа хватает надолго — повторный `/login` нужен, только если Prom разлогинит.
- Проверяет баланс по расписанию и шлёт уведомление при падении ниже порога и уходе в минус, повторяет напоминание.
- Кнопка «Пополнить» ведёт на страницу пополнения Prom (автопополнение — следующий этап).

## Как получается баланс

У публичного API Prom.ua **нет** метода «баланс кошелька» — там только заказы/товары/ТТН. Поэтому:

- **cabinet** — бот читает точную цифру из кабинета по сохранённой сессии. Основной источник.
- **api** — оценка по новым заказам через публичный API-токен. Резерв, если сессия отвалилась.
- **both** (рекомендуется) — сначала кабинет, при сбое — оценка по API.

## Деплой на Railway (с телефона/браузера, без ПК)

### 1. Создай бота в Telegram
Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → скопируй `TELEGRAM_TOKEN`.
Свой `TELEGRAM_CHAT_ID` узнаешь у [@userinfobot](https://t.me/userinfobot) (пришлёт число).

### 2. Залей код на GitHub
Загрузи эту папку в новый репозиторий (можно прямо через сайт github.com: New repository → Upload files).

### 3. Создай проект на Railway
1. [railway.app](https://railway.app) → **New Project** → **Deploy from GitHub repo** → выбери репозиторий. Railway соберёт по `Dockerfile` сам.
2. Открой сервис → вкладка **Variables** → добавь переменные (см. таблицу ниже). Минимум:
   `TELEGRAM_TOKEN`, `TELEGRAM_CHAT_ID`, `PROM_LOGIN`, `PROM_PASSWORD`, `DATA_DIR=/data`.
   (Опционально `PROM_API_TOKEN` для резервной оценки — токен берётся в кабинете Prom с телефона: Налаштування → Управління API-токенами.)
3. Вкладка **Volumes** → **New Volume** → mount path укажи **`/data`**. Это чтобы сессия и настройки не терялись при перезапусках.
4. Railway задеплоит автоматически. В логах увидишь «Бот запущен».

### 4. Войди в кабинет — один раз
Напиши боту `/login`. Он откроет вход Prom в облаке, введёт логин/пароль и попросит **SMS-код** — пришли код сообщением в чат. После «✅ Вход выполнен» бот читает точный баланс. Больше входить не нужно, пока Prom не разлогинит (тогда бот сам напишет — повторишь `/login`).

> **Проверь адрес кошелька.** Открой свою страницу баланса в кабинете Prom, скопируй её URL и впиши в переменную `PROM_BALANCE_URL`. Если бот не находит цифру — поправь `PROM_BALANCE_REGEX` под формат, в котором показан баланс.

## Команды бота

| Команда | Действие |
|---|---|
| `/login` | войти в кабинет (один раз, SMS-код в чат) |
| `/balance` | проверить баланс прямо сейчас |
| `/status` | последнее значение и настройки |
| `/threshold 300` | задать порог «мало денег» (грн) |
| `/topup` | кнопка со ссылкой на пополнение |

## Переменные окружения

| Параметр | Смысл |
|---|---|
| `TELEGRAM_TOKEN` | токен бота от @BotFather |
| `TELEGRAM_CHAT_ID` | твой chat_id (кому слать уведомления) |
| `PROM_LOGIN` / `PROM_PASSWORD` | данные входа в кабинет (для `/login`) |
| `PROM_LOGIN_URL` | страница входа (по умолчанию my.prom.ua) |
| `PROM_BALANCE_URL` | адрес страницы кошелька в кабинете |
| `PROM_BALANCE_REGEX` | регэксп для числа баланса |
| `DATA_DIR` | папка тома для сессии и БД (`/data` на Railway) |
| `LOW_THRESHOLD` | порог предупреждения, грн |
| `CHECK_INTERVAL_MIN` | как часто проверять, мин |
| `REPEAT_ALERT_HOURS` | повтор напоминания при низком балансе, ч |
| `BALANCE_SOURCE` | `cabinet` / `api` / `both` |
| `PROM_API_TOKEN` | токен публичного API (резервная оценка) |
| `API_ESTIMATE_START_BALANCE` | стартовый баланс для оценки, грн |
| `PROM_TOPUP_URL` | ссылка для кнопки пополнения |

## Альтернатива: свой VPS (Docker)

Если вместо Railway хочешь VPS:
```bash
cp .env.example .env && nano .env      # заполни, DATA_DIR=/data
docker compose up -d --build
docker compose logs -f
```
Том `./data` смонтируется в `/data`. Вход так же — командой `/login` в чате.

## Про долговечность входа

Сессия переписывается свежими куками при каждой проверке баланса, поэтому пока бот работает и регулярно проверяет — вход держится долго (недели, обычно месяц+). Если Prom всё же разлогинит по своим правилам безопасности, бот пришлёт сообщение — тебе останется один раз отправить `/login` и код из SMS. Никакого ПК.

## Дальше: автопополнение

Полная оплата из бота (без перехода на сайт) делается через платёжный провайдер (LiqPay/Portmone) и требует настройки провайдера и хранения платёжных данных. Это отдельный этап — архитектура к нему готова (кнопка `/topup` заменится на сценарий оплаты).

## Файлы

- `bot.py` — бот, команды, планировщик, логика уведомлений
- `login_flow.py` — вход в кабинет из Telegram (с SMS-кодом)
- `prom_scraper.py` — чтение точного баланса из кабинета
- `prom_client.py` — оценка баланса по публичному API
- `balance.py` — выбор источника (кабинет → API)
- `storage.py` — состояние (SQLite на томе)
- `config.py` — конфигурация из переменных окружения
- `save_session.py` — необязательный вход с ПК (если когда-нибудь понадобится)
